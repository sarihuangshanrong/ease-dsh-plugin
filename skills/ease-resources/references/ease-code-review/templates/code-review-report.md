## Findings

For each finding record severity, confidence, file/location, trigger, impact, evidence, remediation, and trade-off.

## Checks Without Findings

Record meaningful areas examined so absence of findings is distinguishable from absence of review.

## Handoffs

Only after the required review coverage is complete; partial/blocked reviews retain findings and report remaining work without starting repair.

- Behavior-preserving changes → `ease-code-refactor`
- Behavior changes or diagnosed fixes → `ease-code-implement`
- Architecture gaps → `ease-architecture`
- Test-only work → `ease-testing`
