# 输出结构参考（Output Structure Reference）

> **此目录仅供 Agent 参考输出文档的结构和章节组织方式。**
>
> - 文件中只有**中性占位符**，展示最终输出文档应回答的问题
- **绝对不可以**将此目录下的文件直接复制到用户项目的 `docs/system/` 目录
- 生成文档时必须基于实际代码、配置、IaC、测试、运行线索和已批准记录，而非复制占位内容
- 文件名与输出文件名相同（`01_SYSTEM_OVERVIEW.md` 等），仅用于对照章节结构

## 用途

| 用途 | 说明 |
|------|------|
| 章节结构参考 | 确定输出文档应包含的标题层级和章节 |
| 问题清单 | 确定每份文档应回答的边界、运行、约束、风险、因果和演进问题 |

## 禁止行为

- 直接复制文件内容到 `docs/system/`
- 将占位文字当作实际输出
- 跳过证据分析，用常见技术栈或“合理架构”补全内容
