# 独立 QA 评估

按问题复杂度使用；短评估可直接在回答中表达，不必套用全部标题。

## 结论与范围

说明评估对象、适用版本/环境、检查范围及重要限制。交付审查给出 SUPPORTED / NEEDS_WORK / INCONCLUSIVE 和主要依据；分析或复盘可只说明发现。

## 发现与建议

每项用三部分表达：

- **问题与触发条件**：具体哪里、在什么条件下出问题或缺少判断依据。
- **依据与影响**：预期来源、实际证据或反例，以及后果；区分产品缺陷、验证方案缺陷和缺少材料。
- **下一步**：有边界的改进或验证建议。

严重性、置信度、责任方、重验标准等仅在有助决策时补充。无可支持的发现就明确说明，不制造问题。

## 按需补充

- **覆盖或验收对照**：要求 → 证据 → 缺口；说明完整检查、抽样和未检查范围，不编造百分比。
- **剩余风险**：结论成立的条件、未知及尚需确认的决策。
- **复盘知识**：产生、逃逸、扩大原因的依据或假设，及候选知识的来源与适用边界。
